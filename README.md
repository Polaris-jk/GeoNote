# GeoNote — สมุดสนามดิจิทัลของนักศึกษาเทคโนโลยีธรณี มข. (v1.5)

(ชื่อเดิม Lodestar และ GEO) เว็บแอป (PWA) สำหรับออกภาคสนาม ใช้ได้ทั้ง iPhone และ Android ไม่มีค่าใช้จ่าย ไม่ต้อง login
ข้อมูลทั้งหมดเก็บในเครื่องผู้ใช้ และใช้งานได้แม้ไม่มีสัญญาณ เปลี่ยนชื่อแล้วข้อมูลเดิมในเครื่องยังอยู่ครบ (ลิงก์ GitHub `/geo/` เหมือนเดิม)

## เปลี่ยนแปลงใน v1.5

ภาพตัดขวางวาดโครงสร้างพื้นฐานได้เพิ่ม 3 แบบ (ทำแบบง่าย ไม่ซับซ้อน)

- **ภาพตัดขวางเป็นภาพตัวอย่างเท่านั้น** มีข้อความเตือนใต้ภาพในแอป และในรูปที่ส่งออก (ใต้ชื่อภาพและในหมายเหตุ)
  - แอปคาดคะเนจากชนิดหินและมุมเอียงที่บันทึกในสนาม ไม่ใช่ผลเจาะสำรวจหรือการตีความ
  - นักธรณีวิทยาต้องพิจารณาความจริงเอง
- **ชั้นหินคดโค้ง: ประทุนคว่ำ (anticline) / ประทุนหงาย (syncline)**
  - แกนชั้นหินคดโค้งวาดเป็นเส้นประจุดแนวตั้ง พร้อมชื่อ ตรงที่มุมเอียงปรากฏเปลี่ยนข้าง
    - ชั้นเอียงออกจากแกน = ประทุนคว่ำ
    - ชั้นเอียงเข้าหาแกน = ประทุนหงาย
  - รอยสัมผัสของหินคู่เดียวกันบนสองปีกของชั้นพับ ถือเป็นชั้นเดียวกันและวางไว้ที่ระดับเดียวกัน
    - ชั้นจึงต่อกันใต้แกน ไม่หักเป็นขั้นแบบใน v1.4
    - รอยสัมผัสที่เลื่อนเองแล้วจะอยู่ที่เดิม อีกปีกขยับตาม
- **รอยชั้นไม่ต่อเนื่อง (unconformity)** หินที่ตั้งเป็น ชั้นปิดทับ วาดทับบนผิวกัดกร่อน
  - ฐานของชั้นปิดทับลากตรงระหว่างจุดที่สัมผัสหินที่แก่กว่า และวาดเป็นเส้นหยัก
  - ถ้าชั้นปิดทับไปถึงปลายแนว ฐานต่อออกไปตามมุมเอียงของชั้นปิดทับเอง
  - ชั้นหินที่แก่กว่าใต้ชั้นปิดทับคำนวณจาก Station ของชั้นนั้นเอง มุมเอียงของชั้นปิดทับไม่ทำให้ชั้นล่างโค้งตาม
- **หินอัคนีแทรกซอน** หินที่ตั้งเป็น แทรกซอน วาดเป็นก้อนที่ผุดตัดผ่านชั้นหิน
  - กว้างเท่าช่วงที่โผล่บนผิวดิน ผนังขยายออกเมื่อลึกลง
  - มุมผนังเลือกได้ 90° / 80° (ค่าเริ่มต้น) / 70° / 60° จากแนวราบ
- **ชนิดของหินในภาพตัดขวาง** แตะชื่อหินในรายการ หิน ใต้ภาพ แล้วเลือก อัตโนมัติ / ชั้นหิน / ปิดทับ / แทรกซอน
  - อัตโนมัติเลือกจากชื่อหิน
    - หินอัคนีแทรกซอน (แกรนิต ไดออไรต์ แกบโบร โดเลอไรต์ …) = แทรกซอน
    - ตะกอนร่วน ศิลาแลง ลูกรัง บะซอลต์ และสัญลักษณ์หน่วย Q (Qa, Qt …) = ชั้นปิดทับ
    - ที่เหลือ = ชั้นหิน
  - แอปบอกในหมายเหตุใต้ภาพว่าตั้งอะไรให้อัตโนมัติ
  - เปลี่ยนชนิดได้เฉพาะในภาพตัดขวาง สมุดบันทึกไม่เปลี่ยน ล้างการแก้ไขทั้งหมดจะคืนเป็นอัตโนมัติ
  - รูปที่ส่งออกมีคำอธิบายเส้นแกนชั้นพับ เส้นหยัก และก้อนแทรกซอน และบอกชนิดของหินในรายการหิน

## เปลี่ยนแปลงใน v1.4

- **ชนิดจุด: Station / Check point** เลือกได้ในหน้าบันทึก (หัวข้อ ชนิดจุด) ค่าเริ่มต้นเป็น อัตโนมัติ
  - อัตโนมัติ: จุดที่มีค่าวัด strike/dip อย่างน้อย 1 ค่าเป็น Station ที่เหลือเป็น Check point (เปลี่ยนตามทันทีเมื่อเพิ่มหรือลบค่าวัด)
  - ตั้งเองเป็น Station หรือ Check point ได้ เลขจุดยังเป็นชุดเดียวกัน (ST-001, ST-002 …)
  - ไฟล์ Export มีคอลัมน์ใหม่ `point_type` (Station / Check point) และใน KML/GPX บอก Type
- **สัญลักษณ์จุดใหม่** ใช้เหมือนกันทั้งหน้า Map (และแผนที่เล็กในหน้า GPS) รูปแผนที่สรุป รายการ Stations และภาพตัดขวาง
  - ■ สี่เหลี่ยม = Station · ● วงกลม = Check point · ▲ สามเหลี่ยม = จุดแรกและจุดสุดท้ายของแนวเดิน (ตามลำดับที่บันทึก)
  - บนหน้า Map สัญลักษณ์ใช้สีตามชนิดหินเหมือนเดิม และมีคำอธิบายสัญลักษณ์ในกล่อง สัญลักษณ์สีหิน
- **ภาพตัดขวาง (Cross section)** เปิดได้จากหน้า Stations ปุ่ม ภาพตัดขวาง
  - **แนวตัด** มีให้เลือก 2 แบบ
    - ตามทางเดิน (ค่าเริ่มต้น): ลากผ่าน Station ตามลำดับที่บันทึก ST-001 → ST-002 → …
    - เส้นตรงตั้งฉากแนวระดับเฉลี่ยของชั้นหิน: Station ที่อยู่นอกแนวถูกฉายลงแนวตามแนวระดับ และบอกว่าห่างแนวเท่าไร
    - กลับด้านซ้าย-ขวาได้ ถ้าแนวเดินหักมุมเกิน 30° จะมีเส้นจุดบอกในภาพ
  - **ความสูงพื้นดิน** มาจาก DEM: Copernicus GLO-30 (30 ม.) ผ่าน Mapterhorn
    - ถ้าเข้า Mapterhorn ไม่ได้ ใช้ SRTM 30 ม. (Terrain Tiles on AWS) แทน
    - ไฟล์ความสูงที่โหลดมาเก็บไว้ในเครื่อง เปิดซ้ำตอนไม่มีเน็ตได้
    - ดาวน์โหลดล่วงหน้าได้ที่ปุ่มแผนที่ในหน้า Map → ดาวน์โหลดความสูงบริเวณนี้ (บริเวณที่เห็นบนจอ อย่างน้อยราว 12 × 12 กม.)
    - ถ้าไม่มีเน็ตและไม่มี DEM ในเครื่อง ใช้ความสูงจาก GPS ของแต่ละ Station แทน (หยาบ ±10–20 ม.)
  - **ชนิดหินและมุมเอียง** ใช้ข้อมูลที่บันทึกในสนามเป็นหลัก ไม่ใช้ขอบหน่วยหินจากแผนที่ 1:250,000
    - รอยสัมผัสอยู่กึ่งกลางระหว่าง Station ที่หินต่างกัน เลื่อนได้
    - ใช้ Bedding ก่อน ถ้าไม่มีใช้ Contact หรือ Foliation (หลายค่าในจุดเดียวเฉลี่ยให้) ส่วน Fault วาดเป็นขีดแดงประ
    - แปลงมุมเอียงจริงเป็นมุมเอียงปรากฏตามแนวตัด: tan(ปรากฏ) = tan(dip) × cos(dip direction − ทิศแนวตัด)
  - **ใต้ดิน** คาดคะเนแบบ dip domain
    - มุมเอียงปรากฏไล่ค่าระหว่าง Station ชั้นหินทุกชั้นขนานกันในแนวตั้ง จึงไม่ตัดกัน
    - ลำดับชั้นบน-ล่างคำนวณจากตำแหน่งที่หินโผล่และมุมเอียงเอง
    - ใต้เส้นประคือชั้นที่ไม่โผล่ให้เห็นในแนวนี้
    - ปิดได้ (เฉพาะผิวดิน)
  - **อัตราส่วนแกนตั้ง (V.E.)** ค่าเริ่มต้นเป็นอัตโนมัติ
    - ขยายให้เห็นความสูงต่ำของพื้นดิน และจำกัดไม่ให้เกิน ×10 / ×5 / ×2 เมื่อชั้นหินเอียงน้อยกว่า 5° / 5–15° / มากกว่า 15°
    - ปรับเองได้ ×1–×20 ขีดมุมเอียงบนภาพเอียงตาม V.E. (ตัวเลขข้างขีดคือมุมเอียงจริงที่วัด)
    - ความลึกที่วาดเลือกได้ หรือให้แอปเลือก
  - **จุดบนภาพตัดขวาง** ใช้สัญลักษณ์เดียวกับแผนที่ วางบนเส้นพื้นดิน ขีดมุมเอียงออกจากสัญลักษณ์
  - **แก้ในภาพตัดขวางได้ทุกจุด** แตะสัญลักษณ์ของจุดบนภาพ หรือแตะในรายการ
    - แก้ชนิดหิน สีหิน มุมเอียง (strike/dip/dip dir) ตำแหน่งรอยสัมผัส
    - ปิด ใช้ข้อมูลจุดนี้ สำหรับหินแปลกปลอม (ก้อนหินที่กลิ้งมา ไม่ใช่หินในที่) หรือเอาจุดออกจากแนว
    - การแก้เก็บแยกกับภาพตัดขวางของโปรเจกต์นั้น **ไม่เปลี่ยนข้อมูลในสมุดบันทึก** และรูปที่ส่งออกจะบอกว่าแก้อะไรไปบ้าง
    - ล้างการแก้ทั้งหมดได้
  - **สีหิน** ตามสีของหินในแอป (ยุคของหมวดหินตามแบบแผนที่ธรณีวิทยาของกรมทรัพยากรธรณี)
    - หินที่พิมพ์เองใช้สีที่แอปจำไว้ ถ้ายังไม่มีจะสุ่มสีที่ไม่ซ้ำให้
    - เปลี่ยนสีได้ เฉพาะในภาพตัดขวาง
  - **บันทึกหรือแชร์รูป** เป็น PNG กว้าง 2400 px มีชื่อโปรเจกต์ แผนที่แนวตัด (ทิศเหนือขึ้น) สัญลักษณ์หิน และเครดิตความสูง
- **Settings → ข้อมูลออฟไลน์ตามภาค:** เพิ่มแถว ความสูงพื้นดิน (DEM) บอกขนาดที่เก็บในเครื่อง และลบได้

## เปลี่ยนแปลงใน v1.3

- **แผนที่สรุป (รูปส่งออกจากหน้า Map):** พื้นหลังเลือกได้ 4 แบบ เรียบ / แผนที่ OSM / ดาวเทียม / ออฟไลน์
  - ครั้งแรกเลือกตามแผนที่ที่ใช้อยู่ในแอป (ดาวเทียมหรือแผนที่ถนน)
  - ไม่มีเน็ต: แผนที่ OSM และดาวเทียมเปลี่ยนไปใช้แผนที่ออฟไลน์ในเครื่องให้เอง (ถ้ามีของบริเวณนั้น) ทำรูปในสนามได้
  - เครดิตของภาพพื้นหลังพิมพ์บนรูปตามแหล่งที่ใช้ (OpenStreetMap, Esri, Sentinel-2) และไม่ทับแถบมาตราส่วน
  - แก้: ข้อความ "โหลดแผนที่ไม่ได้" ค้างอยู่แม้โหลดได้แล้ว
  - เร็วขึ้น: เปลี่ยนขนาดรูปหรือสีไม่ต้องโหลดแผ่นแผนที่ใหม่ ตัวหนังสือบนแผนที่ถนนอ่านง่ายขึ้นเมื่อดูรูปบนมือถือ
- **Settings เรียงใหม่:** Project → ภาษา → ธีมสี → GPS → Coordinates → ข้อมูลออฟไลน์ตามภาค → Smart Photo → เซนเซอร์วัดชั้นหิน → สิทธิ์ GPS และเข็มทิศ → Storage → About
- **ธีมสีเพิ่ม 7 แบบ** (การ์ดเลือกธีมแสดงหน้าจอตัวอย่างจริงของแต่ละธีม)
  - สมุดสนาม: กระดาษเหลืองกันน้ำ ตาราง 5 มม. · แผนที่ภูมิประเทศ: เส้นชั้นความสูง · พิมพ์เขียว: กริดเขียนแบบ
  - รุ่งอรุณ ([Rosé Pine Dawn](https://rosepinetheme.com)) แถบชั้นหินใต้หัวแอป · แสงเหนือ ([Nord](https://www.nordtheme.com)) ปุ่มไล่สี · มอคค่า ([Catppuccin Mocha](https://catppuccin.com))
  - แสงแดงกลางคืน: ทุกอย่างรวมทั้งแผนที่เป็นสีแดง ถนอมสายตาตอนมืด
- **หน้า Map:** ปุ่ม หน่วยหิน และปุ่มแผนที่ใหญ่ขึ้น (60 px) ไอคอนกับตัวหนังสืออยู่กึ่งกลาง
- **Smart Photo:** Lat/Long เหลือทศนิยม 3 ตำแหน่ง (Grid Ref และ UTM ยังบอกตำแหน่งละเอียดถึงเมตร) รูปที่เก็บไว้วาดใหม่ให้เอง
- **หน้า GPS และหน้า Station:** เพิ่มแถว Lat/Long ใต้ UTM (เหนือ Accuracy) ทศนิยมเต็มตามที่ GPS ให้มา สูงสุด 8 ตำแหน่ง

## เปลี่ยนแปลงใน v1.2

- **แผนที่ออฟไลน์แบ่งเป็นชิ้นละ 20 MB** อัปขึ้น GitHub ผ่านหน้าเว็บได้ (หน้าเว็บรับไฟล์ไม่เกิน 25 MB) แอปดาวน์โหลดทุกชิ้น ต่อกัน และตรวจขนาดให้เอง ถ้าเน็ตหลุดระหว่างทางจะลองชิ้นนั้นใหม่
- **เปลี่ยนภาษาได้ ไทย / English** ที่ Settings → ภาษา · Language เปลี่ยนแล้วหน้าจอเปลี่ยนทันที แอปจำค่าไว้
  - เปิดแอปครั้งแรก ใช้ภาษาตามภาษาของมือถือ (มือถือภาษาไทย → ไทย, ภาษาอื่น → English)
  - แปลครบทุกหน้า: ข้อความ ปุ่ม แจ้งเตือน หน้าต่างยืนยัน หน้าโหลด ชื่อภาค ชื่อธีม ชื่อหมวดหิน และแถบข้อมูลบน Smart Photo
  - โหมด English ซ่อนชื่อหินภาษาไทย (เช่น Sandstone แทน Sandstone หินทราย) ชื่อในแผนที่ออฟไลน์เป็นภาษาอังกฤษ
  - ไฟล์ Export ไม่เปลี่ยนตามภาษา (หัวคอลัมน์เป็นภาษาอังกฤษ และมีคอลัมน์ lithology_th เหมือนเดิม)
  - ข้อความทุกจุดเขียนคู่กันในโค้ด `t('ไทย', 'English')` (ดู `js/i18n.js`) เพิ่มข้อความใหม่ให้เขียนแบบเดียวกัน

## เปลี่ยนแปลงใน v1.0

- **ชื่อใหม่ GeoNote** พร้อมไอคอนใหม่ (สมุดสนาม ดาวเหนือ ภูเขา ลำน้ำ ปากกา) ในโฟลเดอร์ `icons/`
- **หน้าโหลดเข้าแอป** ราว 3 วินาที แสดงครั้งเดียวต่อการเปิดแอปหนึ่งครั้ง (แตะเพื่อข้ามได้)
- **ธีมสี 6 แบบ** เลือกได้ที่ Settings → ธีมสี
  - **GeoNote** (ค่าเริ่มต้น) ขาวมินิมอล โทนเอิร์ธ สีน้ำเงินเทาตามไอคอน
  - **หินทราย** ครีมอุ่น สีดินเผา · **ป่าเขา** เขียวตะไคร่ · **บะซอลต์** เทาเข้ม สีทราย
  - **กลางคืน** ดำสนิท ประหยัดแบต (ธีมเดิม) · **กลางแดด** ขาว-ดำ ตัดกันชัด
  - ปุ่ม ☀ มุมขวาบนสลับเป็นธีมกลางแดดชั่วคราว แตะอีกครั้งเพื่อกลับธีมที่เลือกไว้
  - สัญลักษณ์บนแผนที่ (จุด Station, strike/dip, เส้นทาง) ยังเป็นสีเหลืองทุกธีม เพื่อให้เห็นชัดบนภาพดาวเทียม

- **แผนที่พื้นหลัง 3 แบบ** (ปุ่มแผนที่ในหน้า GPS และ Map) เปิดแอปครั้งแรกเป็น **ภาพถ่ายดาวเทียม**
  1. **แผนที่ OpenStreetMap** ถนน หมู่บ้าน เมือง (ต้องต่อเน็ต)
  2. **ภาพถ่ายดาวเทียม** Esri World Imagery ≈0.3–1 m เมื่อใส่ ARCGIS_API_KEY ใน `js/config.js` (ต้องต่อเน็ต)
  3. **แผนที่ออฟไลน์** แบ่งตามภาค เก็บในเครื่อง ใช้ได้โดยไม่ต้องต่อเน็ต
  - เมื่อไม่มีเน็ต แอปเปลี่ยนไปใช้แผนที่ออฟไลน์ให้เอง และกลับเมื่อมีเน็ต
- **ข้อมูลออฟไลน์ทั้งประเทศ แบ่ง 6 ภาค** (ภาคเหนือ ภาคตะวันออกเฉียงเหนือ ภาคกลาง ภาคตะวันออก ภาคตะวันตก ภาคใต้) ดู/โหลด/ลบได้ที่ Settings → ข้อมูลออฟไลน์ตามภาค
  - **ภาคตะวันออกเฉียงเหนือติดมากับแอป:** หน่วยหินโหลดพร้อมแอป แผนที่ออฟไลน์ของภาคนี้โหลดเองเบื้องหลังครั้งแรกที่เปิดแอปตอนมีเน็ต
  - ภาคอื่น: แตะดาวน์โหลดทีละภาค ได้ทั้งแผนที่และหน่วยหินของภาคนั้น
  - ขอบเขตภาคเป็นกรอบสี่เหลี่ยมโดยประมาณ (`js/regions.js`)
- **ชั้นหน่วยหิน 1:250,000 ของกรมทรัพยากรธรณี** (หน้า Map → ปุ่ม **หน่วยหิน**)
  - สีตาม legend ของกรมทรัพยากรธรณี แตะบนแผนที่เพื่อดูสัญลักษณ์หน่วยหิน ชื่อหมวดหิน (หมวดหินหลักของกลุ่มหินโคราช) และยุค
  - ถ้าภาคที่อยู่กลางจอยังไม่มีในเครื่อง จะมีปุ่ม **โหลดหน่วยหิน<ภาค>**
  - หน้า Station แสดงหน่วยหินตามแผนที่ใต้ช่อง Lithology เมื่อมีพิกัด

### GPS แบบแตะครั้งเดียว

GeoNote ไม่เปิด GPS ค้างไว้เลย
- **ดูตำแหน่ง** เปิด GPS หาพิกัดปัจจุบัน แล้วปิดเองเมื่อได้ความแม่นยำตามที่ตั้งไว้ (ค่าเริ่มต้น ±5 m) หรือครบ 30 วินาที แตะ **ใช้ค่านี้** เพื่อหยุดก่อนได้
- **NEW STATION** สร้าง Station แล้วเปิด GPS ปักพิกัดของ Station นั้นแบบเดียวกัน
- พิกัดล่าสุดถูกจำไว้ เปิดแอปครั้งต่อไปจะเห็นค่าเดิมพร้อมเวลา โดยไม่ต้องเปิด GPS

### Grid Reference 6 หลัก

- อ่านแบบเดียวกับแผนที่: 3 หลักแรกคือ Easting 3 หลักหลังคือ Northing ในจัตุรัส 100 km (ตัวอักษรเช่น 48Q TD พิมพ์ไว้ขอบระวาง) ตัดเศษเป็นช่องละ 100 m
- คำนวณบน WGS84 ตรงกับแผนที่ภูมิประเทศ 1:50,000 ที่นักศึกษาใช้ (WGS84)
- ไฟล์ export มีคอลัมน์ `grid_ref` (เช่น 688 189) และ `mgrs` (ละเอียด 1 m เช่น 48QTD6885318979)

### วัด Strike/Dip ด้วยเซนเซอร์

1. หน้า Station → Structure → **วัดด้วยเซนเซอร์** (iPhone จะถามสิทธิ์เซนเซอร์ แตะอนุญาต)
2. เลือกชนิดโครงสร้างด้านบน (Bedding, Joint, Fault …)
3. วาง**หลังมือถือ**แนบกับผิวชั้นหิน หน้าจอหงายขึ้น ถือนิ่ง ๆ แถบจะเต็มใน 1.5 วินาทีแล้วล็อกค่าเอง (สั่นและมีเสียง) หรือแตะ **ล็อกค่านี้**
4. **บันทึกค่านี้** หรือ **บันทึก แล้ววัดต่อ** (ยกไปวางบนระนาบถัดไป แอปจะไม่ล็อกค่าเดิมซ้ำ)

- ปุ่มเซนเซอร์ท้ายแถวการวัด ใช้วัดค่าแถวนั้นใหม่ ถ้าพิมพ์แก้ค่าเอง แถวนั้นจะถือเป็นค่ากรอกเอง
- ทิศอ้างทิศเหนือตาม Magnetic declination ใน Settings (0 = ทิศเหนือแม่เหล็กแบบ Brunton)
- **ปรับศูนย์ (ไม่บังคับ แต่แนะนำ):** Settings → เซนเซอร์วัดชั้นหิน → ปรับศูนย์ วางมือถือบนโต๊ะ รอให้อ่านค่า แล้วหมุนกลับหัว 180° วางที่เดิม ทำใหม่เมื่อเปลี่ยนเคส
- ผิวหินขรุขระหรือชั้นเอียงน้อย ให้วางบนสมุดหรือแผ่นแข็งที่แนบผิวชั้น เพื่อเฉลี่ยความขรุขระ
- อยู่ห่างค้อนและเหล็ก ถ้าแอปเตือนว่าเข็มทิศคลาดเคลื่อน ให้หมุนมือถือเป็นเลข 8 แล้ววัดใหม่ ค่าสำคัญควรเทียบกับเข็มทิศธรณี

### Smart Photo และทิศที่ถ่าย

- **ถ่ายรูป** เปิดกล้องในแอป ทิศบันทึก ณ ตอนกดชัตเตอร์ ถ้าใช้ **กล้องปกติ** ทิศอ่านตอนแตะปุ่ม (แสดงเป็น ≈) และถ้ารูปมีทิศใน EXIF จะใช้ค่านั้นแทน
- ทุกรูปมี Smart Photo เก็บไว้ในแอป (วาดใหม่ให้เองเมื่อข้อมูล Station เปลี่ยน)
- กด **SAVE STATION** แล้ว Smart Photo ของรูปใหม่จะบันทึกลงเครื่องเอง: Android อยู่ในโฟลเดอร์ Download (เห็นในแกลเลอรี) ปิดได้ใน Settings → Smart Photo
- iPhone: เว็บแอปบันทึกรูปลงเครื่องเองไม่ได้ (iOS ต้องให้แตะยืนยัน) ให้แตะรูป → ไอคอนแชร์มุมซ้ายล่าง → Save Image
- แตะรูป → ไอคอนแชร์ ส่งเข้า LINE หรือใส่รายงานได้เลย ปัดซ้าย-ขวาเพื่อดูรูปอื่น ปัดลงเพื่อปิด
- ทำทั้งโปรเจกต์ทีเดียว: EXPORT → **Smart Photos**

### ภาพถ่ายดาวเทียม

แอปใช้ภาพแรกที่ตั้งค่าไว้ใน `js/config.js` เรียงตามนี้

| ภาพ | ความคม | ต้องทำอะไร |
|---|---|---|
| Google (Map Tiles API) | ราว 0.3–0.5 m | key + เปิด Billing ใน Google Cloud (ต้องผูกบัตร) ฟรี 100,000 tiles/เดือน |
| Esri World Imagery | ราว 0.3–1 m | key จากบัญชีฟรี ArcGIS Location Platform เกินโควตาฟรีแล้วหยุด ไม่ตัดเงิน (ถ้าไม่เปิด pay-as-you-go) |
| Sentinel-2 cloudless 2024 (EOX) | 10 m | ไม่ต้องทำอะไร (ค่าเริ่มต้น) |

**Google:**
1. ไปที่ console.cloud.google.com สร้าง Project แล้วเปิด Billing (ผูกบัตร)
2. เปิดใช้ **Map Tiles API** (APIs & Services → Library)
3. สร้าง API key (APIs & Services → Credentials) แล้วตั้งข้อจำกัด
   - Application restrictions → Websites → `https://polaris-jk.github.io/*`
   - API restrictions → Map Tiles API
4. **กันโดนเก็บเงิน:** APIs & Services → Map Tiles API → Quotas ตั้งจำนวน 2D tiles ต่อวันไว้ราว 3,000 (30 วัน ≈ 90,000 ไม่เกินโควตาฟรี 100,000) เกินแล้วภาพหยุดโหลด ไม่ตัดเงิน และตั้ง Budget alert ไว้ด้วย
5. ใส่ key ใน `GOOGLE_MAPS_API_KEY = '...'` ใน `js/config.js` บน GitHub แล้ว Commit

**Esri:**
1. สมัครบัญชีฟรี ArcGIS Location Platform ที่ location.arcgis.com
2. สร้าง API key ที่ให้สิทธิ์ Location services → Basemaps → Static basemap tiles และจำกัด Referrer เป็น `https://polaris-jk.github.io`
3. ใส่ใน `ARCGIS_API_KEY = '...'`
4. key มีอายุไม่เกิน 1 ปี ต้องสร้างใหม่ทุกปี

ข้อควรรู้:
- ถ้าใส่ทั้งสอง key แอปใช้ Google ก่อน ถ้า Google ใช้ไม่ได้จะเปลี่ยนเป็น Esri ให้เอง
- แก้ `js/config.js` แล้วไม่ต้องเปลี่ยน VERSION มือถือรับค่าใหม่เองเมื่อเปิดแอปตอนมีเน็ต
- ภาพดาวเทียมต้องต่อเน็ต ไม่ได้เก็บไว้ใช้ offline (แผนที่ปกติยังเก็บเหมือนเดิม)
- Google ห้ามเก็บภาพไว้ใช้ offline และต้องแสดงเครดิต "Google Maps" กับลิขสิทธิ์ภาพ ซึ่งแอปแสดงให้แล้วที่มุมแผนที่
- ห้ามใช้ลิงก์ภาพ Google แบบไม่มี key (mt1.google.com) ผิดเงื่อนไขของ Google

### เวลาที่บันทึก

เวลาของแต่ละ Station คือเวลาที่กด **NEW STATION** การเข้าไปแก้ไขภายหลังไม่เปลี่ยนเวลานี้ (เวลาแก้ไขล่าสุดแสดงแยกไว้ท้ายหน้า Station)
แผนที่สรุปนับเวลารวมจาก Station แรกถึง Station สุดท้ายตามเวลานี้

### แผนที่สรุป (รูปสำหรับ IG)

หน้า Stations → **แผนที่สรุปโปรเจกต์** (หรือปุ่มรูปภาพในหน้า Map)
- **ขนาดรูป:** โพสต์ 4:5 (1080×1350) หรือสตอรี่ 9:16 (1080×1920 เว้นขอบบนล่างไว้ให้แถบของ IG)
- **พื้นหลัง:** แผนที่ OpenStreetMap (ต้องมีเน็ต) หรือพื้นเรียบ
- **สี:** มืด หรือ สว่าง
- **หมุนได้:** แอปหมุนแผนที่ให้เส้นทางเต็มกรอบแนวตั้ง ลูกศรทิศเหนือชี้ทิศจริงเสมอ เลือก **ทิศเหนือขึ้นเสมอ** ถ้าไม่ต้องการให้หมุน
- กด **บันทึกหรือแชร์รูป** แล้วเลือก Instagram หรือบันทึกลงอัลบั้ม
- ถ้าใช้พื้นหลังแผนที่ ให้คงเครดิต © OpenStreetMap contributors ไว้ในรูปตามเงื่อนไขของข้อมูล

### Export

แตะ **EXPORT** ในหน้า Stations แล้ว
1. เลือกโปรเจกต์ (เลือกได้หลายโปรเจกต์ หรือ **เลือกทั้งหมด**)
2. เลือกรูปแบบไฟล์

| รูปแบบ | ใช้ทำอะไร |
|---|---|
| **Project ZIP** (แนะนำ) | ทุกอย่างในไฟล์เดียว: Excel, CSV, GeoJSON, KML, GPX, รูปภาพ และ `project.json` สำรองข้อมูล ถ้าเลือกหลายโปรเจกต์ จะแยกโฟลเดอร์ละโปรเจกต์ |
| **Excel (.xlsx)** | แผ่นงาน Stations, Structures, Samples หัวตารางล็อกไว้และกรองได้ |
| **CSV** | ตาราง Stations สำหรับ Google Sheets หรือโปรแกรมอื่น |
| **GeoJSON Stations** | จุด Station สำหรับ QGIS / ArcGIS |
| **GeoJSON Structures** | หนึ่งจุดต่อหนึ่งการวัด ใช้ทำสัญลักษณ์ strike/dip |
| **KML** | เปิดใน Google Earth พร้อมเส้นทางตามลำดับเวลา |
| **GPX** | จุดและเส้นทางสำหรับแอป GPS อื่น ๆ |
| **Smart Photos** | ทุกรูปพร้อมแถบข้อมูล Station (ZIP) |

- ไฟล์ export มีทั้ง UTM และ Lat/Long เสมอ ไม่ว่าหน้าจอจะแสดงแบบไหน และมีคอลัมน์ `project` บอกว่าแต่ละแถวมาจากโปรเจกต์ไหน
- วันที่และเวลาในไฟล์คือเวลาที่บันทึก Station (ตอนกด NEW STATION)
- CSV เป็น UTF-8 แบบมี BOM ภาษาไทยจึงแสดงถูกต้องใน Excel

## สิทธิ์ GPS และเข็มทิศ

GeoNote ไม่ขอสิทธิ์อะไรตอนเปิดแอป จะถามเฉพาะตอนแตะปุ่มที่ต้องใช้ GPS หรือเข็มทิศ

- **Android:** Chrome จำสิทธิ์ตำแหน่งไว้ และเข็มทิศไม่ต้องขอสิทธิ์
- **iPhone:** iOS เป็นคนกำหนดว่าจะถามซ้ำบ่อยแค่ไหนสำหรับเว็บแอป ลดการถามได้โดย
  1. Settings → Privacy & Security → Location Services → Safari Websites → While Using the App
  2. Settings → Apps → Safari → Location → Allow (iOS 17 ลงไปอยู่ที่ Settings → Safari → Location)

  เข็มทิศบน iPhone ต้องแตะอนุญาตใหม่ทุกครั้งที่เปิดแอป เป็นข้อจำกัดของเว็บแอปบน iOS ที่แก้จากฝั่งแอปไม่ได้ แอป APK บน Android จะไม่มีปัญหานี้

## ขึ้น GitHub Pages ฟรี เพื่อใช้บนมือถือ

GPS และเซนเซอร์ใช้ได้เฉพาะเว็บที่เปิดผ่าน https ซึ่ง GitHub Pages ให้มาฟรี

1. สร้าง repository ใหม่ใน GitHub ชื่อ `geo` แบบ **Public**
2. แตก zip ก่อน (คลิกขวา → Extract All) แล้วเปิดโฟลเดอร์ `geo`
3. ในหน้า repo กด **Add file → Upload files** แล้ว**ลาก**ทุกอย่างข้างในโฟลเดอร์ `geo` (ทั้งไฟล์และโฟลเดอร์ css, fonts, icons, js, vendor) มาวาง ห้ามใช้ปุ่ม choose your files เพราะเลือกโฟลเดอร์ไม่ได้
4. รอจนรายการไฟล์ขึ้นครบ แล้วกด **Commit changes**
5. ไปที่ **Settings → Pages** ตั้ง Source เป็น **Deploy from a branch**, Branch เป็น `main` และ `/ (root)` แล้วกด **Save**
6. รอ 1–2 นาที จะได้ลิงก์ `https://<ชื่อผู้ใช้>.github.io/geo/`

### อัปเดตเป็นเวอร์ชันใหม่

ทำขั้นที่ 2–4 ซ้ำกับไฟล์เวอร์ชันใหม่ GitHub จะเขียนทับไฟล์เดิมให้เอง ข้อมูลที่บันทึกไว้ในมือถือยังอยู่ครบ เพราะเก็บในเครื่อง ไม่ได้อยู่บน GitHub
เปิดแอปในมือถือหลังอัปเดต แล้วปิดและเปิดใหม่อีกครั้ง จะได้เวอร์ชันล่าสุด
ถ้าใส่ key ภาพดาวเทียมไว้ใน `js/config.js` แล้ว อย่าอัปโหลด `js/config.js` จากเวอร์ชันใหม่ทับ (key จะหาย)

ถ้าแก้โค้ดเอง ให้เปลี่ยน `VERSION` ในบรรทัดแรก ๆ ของ `sw.js` ด้วย (เช่น `geo-v0.3.1`) มือถือจึงจะโหลดเวอร์ชันใหม่ ถ้าเพิ่มไฟล์ใหม่ ให้เพิ่มชื่อไฟล์ในรายการ `SHELL` ใน `sw.js`

## ข้อควรรู้ก่อนออกภาคสนาม

- **ข้อมูลอยู่ในเครื่องเท่านั้น** ให้ Export เป็น Project ZIP เก็บไว้หลังออกสนามทุกวัน
- **บน iPhone ถ้าลบไอคอน GeoNote ออกจากหน้าจอโฮม ข้อมูลในแอปจะถูกลบด้วย** และถ้าใช้ผ่าน Safari โดยไม่ติดตั้ง ข้อมูลอาจถูกล้างเมื่อไม่ได้เปิดเกิน 7 วัน
- **แผนที่ offline:** ก่อนออกสนาม เปิดแผนที่บริเวณที่จะไปขณะมีเน็ต เลื่อนดูและซูมระดับที่ต้องใช้ ส่วนที่เคยเปิดจะถูกจำไว้ใช้ตอนไม่มีสัญญาณ
- **Elevation:** iPhone ให้ความสูงจากระดับทะเล ส่วน Android ให้ความสูงจากทรงรี WGS84 ซึ่งในไทยต่างกันราว 10–40 m (ขอนแก่นราว 30 m) GeoNote แปลงค่าของ Android ด้วยแบบจำลอง geoid EGM96 ให้เป็นระดับทะเลแล้ว แต่ความสูงจาก GPS ยังคลาดเคลื่อนได้หลายเมตร
- **เข็มทิศมือถือ:** อยู่ห่างค้อน แม่เหล็ก และหินที่มีแร่แม่เหล็ก ถ้าค่ากระโดด ให้หมุนโทรศัพท์เป็นเลข 8 เพื่อปรับเทียบ ค่าที่สำคัญควรยืนยันด้วย Brunton
- **ลบด้วยการปัด** จะถามยืนยันก่อนทุกครั้ง และลบรูปของ Station นั้นด้วย ลบแล้วกู้คืนไม่ได้

## นำเข้า QGIS

- **GeoJSON:** ลาก `stations.geojson` หรือ `structures.geojson` เข้า QGIS ได้ทันที (EPSG:4326)
- **CSV:** Layer → Add Layer → Add Delimited Text Layer → X = `utm_e`, Y = `utm_n`, CRS ตามคอลัมน์ `utm_epsg` (EPSG:32648 สำหรับโซน 48N) หรือใช้ X = `lon`, Y = `lat` กับ EPSG:4326
- **KML / GPX:** ลากเข้า QGIS ได้เหมือนกัน (มีทั้งจุดและเส้นทาง)
- **สัญลักษณ์ strike:** เปิด `structures.geojson` → Symbology → Simple Marker → Shape: Line → Rotation แบบ data-defined เป็นฟิลด์ `strike` แล้วใส่ Label เป็นฟิลด์ `dip`

## รอบถัดไป

1. วัด Lineation (trend/plunge) ด้วยเซนเซอร์
